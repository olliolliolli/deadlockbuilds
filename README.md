# Deadlock Builds — оверлей з актуальними збірками

Показує поверх гри найкращі збірки на героя, за якого ти граєш, порахувані за
матчами **після останнього патча** (дані з community-API deadlock-api.com).

Програма не читає пам'ять гри й не вбудовується в неї, тому ризику бану VAC немає.

## Варіант 1: exe-файл (рекомендовано)

Python не потрібен. Є два способи отримати exe-файл:

- **З GitHub.** Сторінка репозиторію → Releases → `latest` → завантаж `DeadlockBuilds.exe`.
  Він автоматично бере готові збірки з сервера і відкривається миттєво.
- **Зібрати на своєму ПК.** Один раз запусти `run.bat`, потім `build_exe.bat`.
  Готовий `DeadlockBuilds.exe` з'явиться в цій папці, і його можна перенести куди завгодно.

Windows SmartScreen може попередити про «невідому програму», бо файл не підписаний
сертифікатом. Натисни «Докладніше» → «Усе одно запустити».

## Варіант 2: з вихідного коду

1. Встанови Python 3.11+ з python.org і постав галочку «Add Python to PATH».
2. Запусти `run.bat`. Перший запуск триває 1–2 хвилини.

У Deadlock: Налаштування → Відео → режим вікна **«Вікно без рамки» / Borderless**.
У повноекранному режимі Windows не покаже оверлей поверх гри.

## Сервер зі збірками (GitHub Actions, безкоштовно)

У папці `.github/workflows` лежать два сценарії:

- `update-data.yml` — кожні 2 години рахує збірки на всіх героїв і всі ранги
  та викладає `builds.json` у гілку `data`;
- `build-exe.yml` — після кожної зміни коду збирає `DeadlockBuilds.exe` у Releases.

Репозиторій має бути **публічним**: так файл даних доступний без пароля, а
GitHub Actions для публічних репозиторіїв безкоштовні без обмежень.
Якщо в репозиторії 60 днів не було змін, GitHub ставить розклад на паузу і
надсилає лист. Розклад вмикається однією кнопкою на вкладці Actions.

Якщо запускаєш з вихідного коду, впиши адресу даних у `config.json`:
`"data_url": "https://raw.githubusercontent.com/<логін>/<репозиторій>/data/builds.json"`.
Без неї програма рахує збірки сама, і це займає кілька секунд на героя.

## Керування

- **Ctrl+X** — показати оверлей і забрати курсор у гри; ще раз — сховати й повернути курсор у гру
- **Ctrl+Shift+X** — режим «крізь клік»: оверлей видно, але миша проходить у гру
- Перетягуй вікно за верхню смугу, розмір змінюй за правий нижній кут
- Вибери героя у випадному списку і ранговий фільтр
- ⟳ — примусово перерахувати без кешу (кеш живе 1 год)

## Автовизначення героя

Оверлей сам перемикається на героя, за якого ти граєш (у хованці й у матчі).
Для цього гра має писати свій консольний лог у файл. Це робить офіційний параметр
запуску `-condebug`. Програма лише читає цей файл, пам'ять гри не зачіпається.

Увімкни один раз: Steam → Бібліотека → Deadlock → ⚙ → Властивості →
Параметри запуску → впиши `-condebug`.

Або натисни «Запустити гру» в оверлеї, і він відкриє Deadlock з цим параметром.

Кнопка **«Авто»** вмикає й вимикає автоперемикання. Якщо папку гри не знайдено
(нестандартна бібліотека Steam), впиши її в `config.json`, у поле `game_dir`,
наприклад `"D:\\SteamLibrary\\steamapps\\common\\Deadlock"`.

## Імпорт збірки в гру

Збірки Deadlock зберігаються на серверах Valve, тому записати їх у гру ззовні
неможливо без втручання в клієнт (а це ризик бану). Натомість програма серед
опублікованих у грі збірок знаходить ту, що найбільше збігається з
рекомендованою, і оновлювалась після поточного патча.

1. Натисни **«Копіювати ID збірки»** у верхній картці оверлея.
2. У грі відкрий магазин → вкладку **«Збірки» (Builds)** → поле пошуку → **Ctrl+V**.
3. Обери знайдену збірку, і гра показуватиме її підказки в магазині.

«Збіг» показує, яку частку рекомендованих предметів містить ця збірка.
Поруч є ще 1–2 альтернативи на випадок, якщо перша не сподобається.

## Як рахується збірка

- **Вікно даних**: беруться матчі з дати останнього патча. Якщо на героя там менше
  1500 матчів (наприклад, патч вийшов учора), вікно автоматично розширюється до
  попереднього патча, і це буде вказано у статусі.
- **Вінрейт предмета** порівнюється тільки з предметами **того ж тіру**. Інакше дорогі
  предмети завжди виглядали б «найкращими», бо їх купують переважно ті, хто вже виграє.
  Число праворуч (наприклад, +2.3) — різниця з середнім по тіру у відсоткових пунктах.
  Для малих вибірок воно згладжується, щоб рідкісні предмети не вистрибували нагору.
- **Етапи** (лейн / середина / пізня гра) визначаються за медіанним часом покупки.
- **Основні** предмети: пікрейт ≥ 8% і не гірший вінрейт за середній. **Ситуативні**:
  рідші або не потрапили в топ, але з помітно кращим вінрейтом.
- **Здібності**: найуспішніший з 5 найпопулярніших порядків прокачки.

## Якщо щось не працює

Відкрий термінал у папці програми і виконай:

```
.venv\Scripts\python -m dlbuilds --doctor
```

Команда перевірить усі запити до API й покаже приклади відповідей.
Скинь мені цей вивід, і я виправлю програму під актуальний формат API.

Збірку можна подивитися й без оверлею:

```
.venv\Scripts\python -m dlbuilds --hero Haze --rank 2
```

Налаштування (гарячі клавіші, прозорість, поріг матчів) зберігаються в
`%APPDATA%\DeadlockBuilds\config.json`. Гарячі клавіші задаються у форматі
`ctrl+x`, `ctrl+shift+x`, `alt+f2` тощо.

Тривалість кожного запиту до API пишеться в `%APPDATA%\DeadlockBuilds\network.log`.

## Швидкість

Відкриті раніше герої показуються одразу із збережених даних, а свіжі
підтягуються у фоні (у підписі під іменем видно «оновлюю…»). Новий герой
завантажується за 1–3 секунди.
